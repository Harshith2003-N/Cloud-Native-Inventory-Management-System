**Cloud-Native Inventory Management System**

**Overview**

The Cloud-Native Inventory Management System is a full-stack application designed to manage inventory records and monitor stock levels. It uses Java and Spring Boot for backend development, MySQL for data storage, and React.js for the user interface.

**Technologies Used**

Java
Spring Boot
Spring Data JPA and Hibernate
REST APIs
MySQL
React.js
Docker and Docker Compose
JUnit 5 and Mockito
Key Features
Inventory record management
Stock monitoring and tracking
RESTful API integration
Database persistence using MySQL and Hibernate
Web-based user interface using React.js
Containerization using Docker
Unit and integration testing

**Project Structure**

backend/ — Spring Boot application
frontend/ — React.js application
docker-compose.yml — Container configuration, if implemented
README.md — Project documentation

**Getting Started**

Clone the repository.
Configure your MySQL database and application properties.
Install the required Java, Maven, Node.js, and npm versions.
Start the Spring Boot backend.
Install frontend dependencies and start the React.js application.
Open the application in your browser.
Purpose

This project demonstrates full-stack application development using Java, Spring Boot, REST APIs, relational database integration, and modern frontend technologies.
